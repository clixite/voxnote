# VoxNote

PWA + app Capacitor d'enregistrement vocal et transcription.

- `apps/web` : SPA Vite + React (PWA desktop/web + shell Capacitor iOS/Android)
- `apps/api` : API Next.js (route handlers) — pipeline de transcription
- `packages/shared` : types partagés

## Démarrer
```bash
pnpm install
pnpm dev:web   # SPA
pnpm dev:api   # API
```
